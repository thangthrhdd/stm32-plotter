# stm32-plotter
2-axis CNC plotter using STM32 controlled by G-code
## USB Stack

This project includes a low-level USB CDC driver developed for STM32F407.

Key features:
- USB device enumeration
- Descriptor management
- Control endpoint (EP0) handling
- Bulk data transfer
- Communication with PC via USB CDC
